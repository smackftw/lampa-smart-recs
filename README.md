# Умные рекомендации для Lampa

Автономный плагин персональных рекомендаций: один JS-файл, без Docker, регистрации и пользовательских API-ключей. История обрабатывается локально, а каталог запрашивается через встроенный TMDB-клиент Lampa.

## Установка

В Lampa откройте **Настройки → Плагины → Добавить плагин** и вставьте:

```text
https://smackftw.github.io/lampa-smart-recs/smart-recs.js
```

Один и тот же адрес используется в веб-версии Lampa и на Android TV. После установки появятся пункт **«Для вас»**, строка рекомендаций на главной и отдельный раздел настроек.

## Как он учится

Плагин учитывает историю, «Нравится», статусы «Просмотрено»/«Брошено», закладки и прогресс фильма. Через контекстное меню любой карточки можно дополнительно выбрать **«Больше похожего»** или **«Меньше похожего»**.

Кандидаты собираются из:

- рекомендаций и похожего контента TMDB для наиболее сильных сигналов;
- поиска по любимым жанрам;
- недельных трендов для разнообразия;
- уже накопленного локального списка рекомендаций Lampa.

Затем плагин оценивает соответствие вкусу, рейтинг, число голосов и свежесть, удаляет просмотренное и снижает повторы одинаковых жанров.

Если история пустая, сразу показываются тренды. Чем больше корректных отметок, тем персональнее становится лента.

## Перенос с компьютера на Android TV

Сам плагин ставится тем же URL. История и стандартные отметки будут одинаковыми на устройствах, если Lampa подключена к одному CUB-профилю и соответствующая синхронизация доступна в используемом плане CUB. Команды «Больше/меньше похожего» пока сохраняются локально на конкретном устройстве и не отправляются наружу.

## Приватность и ключи

- Плагин не имеет собственного backend и не загружает полный профиль или историю на сторонний сервер.
- Пользовательские TMDB-ключи не нужны: используется `Lampa.Api.sources.tmdb`, включая выбранный в Lampa прокси.
- Для получения похожего контента встроенному TMDB-клиенту передаются отдельные ID опорных фильмов — так же работает штатный рекомендатор Lampa.
- В репозитории нет AI-ключей, паролей или токенов.
- Кэш и дополнительные оценки лежат в namespaced-хранилище Lampa.

Для будущих закрытых функций предусмотрен API серверной авторизации. Код доступа отправляется только HTTPS-шлюзу, а полученный краткоживущий токен хранится в памяти до перезапуска. Подробнее: [docs/SECURITY.md](docs/SECURITY.md).

## Ограничения

- Ручные оценки плагина пока не синхронизируются между устройствами.
- Качество зависит от полноты карточек и истории Lampa.
- На первом построении требуется несколько запросов; затем используется кэш 3–24 часа.
- Плагин показывает метаданные и рекомендации, но не предоставляет источники видео.

## Разработка

Требуется Node.js 20+ только для тестов; сам плагин не имеет runtime-зависимостей.

```bash
npm ci
npm test
```

Опциональная проверка на локально собранной Lampa и установленном Chrome:

```powershell
$env:CHROME_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
$env:LAMPA_URL='http://127.0.0.1:3000'
npm run test:integration
```
