## Что предоставляет Lampa

Lampa экспортирует плагику глобальные `Favorite`, `Timeline`, `Api`, `Recomends`, `ContentRows`, `SettingsApi`, `Manifest`, компоненты и события. `Lampa.Api.sources.tmdb.get()` автоматически добавляет внутренний TMDB-ключ, язык, детский фильтр и выбранный пользователем прокси. Поэтому требовать от пользователя отдельный TMDB-ключ для клиентского рекомендатора не нужно.

Lampa технически предоставляет `Favorite` и `Timeline`, но рекомендатор намеренно их не читает: скрытые закладки, «Позже» и история не должны влиять на профиль без явного действия пользователя.

В Lampa уже есть простой `core/recomend.js`, основанный на истории. Новый плагин не использует его выдачу и самостоятельно получает кандидатов TMDB только из явных бинарных оценок; при пустом профиле показывает тренды.

## Почему исходный movie-recommender не взят за основу

Проект решает более широкую задачу: FastAPI, SQLite, TMDB, CUB, TorrServer, Jackett, Telegram, YouTube, отзывы и опциональный Anthropic. Для простого TV-плагина это существенно увеличивает установку и поверхность атаки.

В просмотренной версии клиентского файла также есть архитектурные проблемы:

- фиксированный удалённый сервер и общий `uid = default`;
- отправка закладок и истории без пользовательской аутентификации;
- событие `full:complite` означает загрузку страницы карточки, а не завершение просмотра;
- поиск `entry.id` внутри `file_view` не соответствует текущей структуре Timeline Lampa;
- репозиторий не содержит отдельного файла лицензии.

Поэтому алгоритм и клиент реализованы независимо, без копирования кода проекта.
